How to play 玩法
1. Teams take turns picking a hidden square. 兩隊輪流翻一格，隊上任何人都可以點。
2. The question pops up for everyone — but in a different spot on each team's board. 題目會同時跳出，但兩隊的位置不一樣！
3. The game picks one uploader per team (📸). 系統每題在每隊指定一位上傳者，輪流換人。
4. Both teams' answers in → square done → next pick. 兩隊都上傳，這格才完成，才能翻下一格。
5. 4 in a row = BINGO!

📘 How to set up Firebase 建立免費的 Firebase 專案（約 10 分鐘）
  1. 打開 console.firebase.google.com，用學校或自己的 Google 帳號登入，按「建立專案」。名稱隨意（例如 photo-bingo），Google Analytics 可以關掉。
  2. 左側選單「建構 Build」→「Realtime Database」→「建立資料庫」。位置選 新加坡 (asia-southeast1)，選「以鎖定模式啟動」。（注意：是 Realtime Database，不是 Firestore。）
  3. 在 Realtime Database 上方點「規則 Rules」分頁，把內容整段換成下面這段，按「發布」。
  4. 回到「專案總覽」，按 </>（網頁）圖示新增網頁應用程式，名稱隨意，不用勾選 Hosting，按「註冊應用程式」。
  5. 畫面會出現一段 const firebaseConfig = { … }，整段複製，貼到下面的框，按「儲存並連線」。
費用：免費的 Spark 方案就夠用，不需要綁信用卡。限制是同時最多約 100 台裝置連線（12 個房間 × 5 人 + 老師沒問題）。
如果貼上的設定裡沒有 databaseURL：到 Realtime Database 頁面，複製上方 https://…firebasedatabase.app 的網址，在設定裡加一行 databaseURL: "那個網址",。

Short videos 免費短片模式

沿用目前的 Firebase Realtime Database，無需啟用 Storage、升級方案或填信用卡。保留原本的房間、照片與進度。

可拍照、錄製最多 10 秒短片及切換前後鏡頭；影片採較低畫質，單檔最多 1 MB。上傳現成影片也受相同限制，超過時請改用遊戲內錄影或縮短影片。

請使用 HTTPS 網址並允許相機／麥克風。維持 Spark 免費方案；儲存或下載流量用完時，服務可能受限，請先以測試房間確認。查看免費額度
